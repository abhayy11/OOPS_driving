# 🚗 OOPS Driving – Highway Drive

A browser-based highway driving game developed using **HTML, CSS, and JavaScript** as part of an Object-Oriented Programming (OOPS) project.

The game allows players to drive on a highway, avoid traffic, earn scores, and challenge themselves as the difficulty increases. It demonstrates JavaScript-based game development, object-oriented programming concepts, keyboard event handling, and browser storage.

## ✨ Features

- **Highway Driving:** Interactive driving gameplay with highway traffic.
- **Keyboard Controls:** Control the vehicle using keyboard inputs.
- **Dynamic Traffic:** Traffic difficulty increases as the game progresses.
- **Scoring System:** Earn points based on gameplay performance.
- **Collision Detection:** Detect collisions between the player's vehicle and traffic.
- **Sound Effects:** Audio feedback for different game events.
- **Increasing Difficulty:** The game becomes more challenging over time.
- **Best Score Tracking:** Saves the highest score using browser Local Storage.
- **Game Over System:** Displays the final score when the player crashes.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Provides the structure of the game and its elements. |
| CSS3 | Handles styling, layout, animations, and visual appearance. |
| JavaScript (ES6) | Implements game logic, controls, scoring, traffic, and interactions. |
| Web Audio API | Generates and manages game sound effects. |
| Local Storage | Stores the player's best score in the browser. |
| DOM Manipulation | Updates game elements and interface dynamically. |

## 🧠 OOPS Concepts

The project demonstrates object-oriented programming principles through JavaScript.

- **Classes and Objects:** Organizing game components and their properties and behaviours.
- **Encapsulation:** Keeping related data and functionality together.
- **Inheritance:** Reusing common functionality through class inheritance, where implemented.
- **Polymorphism:** Supporting different behaviours through shared interfaces or overridden methods, where implemented.

## 🎯 Game Functionality

1. Start the game.
2. Control the vehicle using keyboard inputs.
3. Avoid collisions with incoming traffic.
4. Earn points while surviving on the highway.
5. Experience increasing traffic difficulty.
6. Try to beat your previous high score.
7. The game ends when a collision occurs.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
- Git (optional, for cloning the repository).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abhayy11/OOPS_driving.git
```

**2. Navigate to the project folder**

```bash
cd OOPS_driving/driving
```

**3. Run the project**

Open `index.html` in your browser.

No additional dependencies or backend setup are required.

## 🌐 Deployment

The project can be deployed using **Vercel** because it is a static website built with HTML, CSS, and JavaScript.

1. Import the GitHub repository into Vercel.
2. Select the `driving` folder as the Root Directory.
3. Choose **Other** as the Framework Preset.
4. Leave the Build Command and Install Command empty.
5. Set the Output Directory to `.`.
6. Click Deploy.
